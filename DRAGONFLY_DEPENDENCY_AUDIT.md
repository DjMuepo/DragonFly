# DragonFly Dependency Audit

Audit date: 2026-10-21. Production source baseline: `2ac30ecb6e69dc06bb55d90556322474c87ea569`. Repository: `DjMuepo/DragonFly`.

## Scope And Evidence Rules

This is an engineering audit, not legal advice or a claim of complete license compliance. **Verified declaration** means an inspected package manifest, model card or license text says so; it does not prove dataset ownership, patent clearance, output rights, or license coverage for every bundled binary. **UNVERIFIED** is explicit wherever evidence is unavailable. Exact versions and terms must be rechecked before acquisition, commercial deployment, fine-tuning or redistribution.

No production configuration, Render deployment, provider selection or existing reconstruction behavior changed. No weights were downloaded and no paid inference ran. The only new runtime-facing file is an unused, standalone local-inference contract; it is not registered with `select_provider()`.

Inventory sources:

- Active application: `eye-expo/package.json`, its lockfile, `app/snap/*`, `src/lib/geometryApi.ts` and Zustand storage.
- Active geometry API: `eye-platform-alpha-geometry-backend/geometry-backend/app/{main,providers,image_preprocessing,mesh_factory,mesh_editing,physical_units,reconstruction_debug}.py`, requirements and Dockerfile.
- Separate broader prototype API: `api/app/`, `api/requirements.txt`, `api/tools/`.
- Separate Next.js landing/sharing app: `web-landing/`; duplicate older frontend under `eye-platform-alpha-geometry-backend/eye-expo/`.
- Deployment: root `render.yaml`, geometry-specific Render example, `deployment/docker-compose.example.yml`, nginx example and bootstrap scripts. These were read, not edited.
- Complete lockfile/declaration inventory: [package-inventory-2026-10-21.json](docs/dependency-audit/package-inventory-2026-10-21.json), generated by `scripts/audit_dependency_inventory.py` with the geometry `.venv312` interpreter, **without network access**. It contains every JS lockfile entry and every locally installed Python distribution with declared license, purpose/evidence limits, commercial caveat, fee caveat and independent alternative. The installed venv is not an SBOM of Render's Docker image.

The JS lock has 674 entries including the root; 672 contain license metadata. The root project and `webgl-constants@1.1.1` have no license metadata in the lockfile. No tracked root `LICENSE` was found; DragonFly ownership/contributor grant terms are **UNVERIFIED**. Do not add a license retroactively without owner approval. Python has no complete transitive lock; several requirements are unpinned and the legacy API repeats entries.

## Priority Independence Risks And Next Decisions

1. Pin/review the actual deployed Replicate model/version and legal service terms before claiming commercial/geographic eligibility; do not expose tokens. Existing private settings were not accessed here.
2. Keep production and evaluation branches separate. Six fresh real-camera originals and paired, human-reviewed quality evidence are still required before any engine switch. Screenshot-based controls are invalid.
3. Provision an owner GPU worker outside the 512 MB HTTP service. A genuine local-model inference, GPU/OOM/cancellation/resource measurements and output parity remain **NOT TESTED**.
4. Choose TripoSR as a licensing/implementation baseline, not a fidelity winner; benchmark other reviewed candidates only with authorized compute. Remove/replace non-commercial auxiliary components before commercial trials.
5. Replace runtime CDN and build/model-download dependencies with reviewed immutable owner mirrors only through a separately approved migration. Avoid silent behavior/configuration changes.
6. Implement durable identity, storage, job state, backups, retention and access control rather than rebranding prototype JSON/SQLite helpers as a complete self-hosted platform.
7. Complete legal review of root DragonFly ownership, third-party notices, model weights, training assets, commercial service terms and derivative-output use. No model in this audit is granted unconditional worldwide commercial approval.
