# DragonFly Application Completion Matrix

Audit date: 2026-10-21. Audited branch: `feature/application-completion`, based on production `main` `2ac30ecb6e69dc06bb55d90556322474c87ea569`.

Status terms: **Verified** means an automated test or direct implementation contract was executed; it does not necessarily mean production integration. **Partial** means a real subset works with material limits. **Defective/unavailable** means the shipped UI/API route is missing, mismatched, or returns an explicit unavailable result. **Demo/placeholder** is not a completed product feature. No status is inferred from a button's presence.

## Safe fixes in this sprint

- Replaced the legacy parametric Print Ready novelty fallback with an explicit heuristic/unavailable label; print time is `Not measured`, and slicer/3MF absence is stated.
- Removed a dead STL/3MF alert placeholder. A real returned parametric STL URL is now the download action and failures are visible.
- Printer submission, print-success event, and paid entitlement checks fail closed when the real integrations do not exist. Nearby sample printers cannot be ordered and are labeled as demonstrations.
- Nearby-printer discovery no longer substitutes a Los Angeles coordinate when location permission is denied; it stops without a search. Print outcome controls are explicitly self-reported.
- Alternate `snap/ai-edit.tsx` applies geometry/calibration revisions through the existing model history and requires a user-entered measurement.
- Account saved-design errors are exposed; deterministic edit capabilities copy is corrected; launch hub labels its tools as previews.

## Verified versus not verified

Automated checks are listed in `DRAGONFLY_COMPLETION_REPORT.md`. Passing deterministic mesh/edit/export tests prove behavior on test meshes and requests, not general AI fidelity, payment, print fulfillment, persistent project storage, or mobile device functionality.
